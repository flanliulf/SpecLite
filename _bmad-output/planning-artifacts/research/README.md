# Research Evidence Boundary（研究证据边界）

本目录保存 historical research evidence，用于说明 SpecLite planning 时参考过的外部样本、技术背景和比较材料。

Research documents 不参与 live planning consistency gate、implementation readiness gate、contract ownership 判断或 release gate 断言。若 research wording 与 live PRD、Architecture、Epics、ADRs 或 owning SPECs 冲突，以 live documents 和 owning SPECs 为准。

Research 中出现的旧术语、外部系统字段名或历史样本描述不得被 implementation agents 当作当前契约。实现前必须读取 `_bmad-output/planning-artifacts/specs/README.md` 中的 owning SPEC reading order。
