# Project Classification（项目分类）

SpecLite 属于 developer tool，交付形态是 CLI tool、AI IDE integration tooling 和 local installer/control plane 的组合。它运行在 AI-assisted SDLC / developer tooling 领域，具备较高的技术和系统复杂度，但不属于医疗、金融、政务等强监管业务域。项目上下文是 brownfield：它不是从零创建方法论内容，而是在既有 SpecLite source/skill 体系之上构建新的安装、状态检查、更新、manifest、IDE adapter、runtime 配置和验证控制面。
