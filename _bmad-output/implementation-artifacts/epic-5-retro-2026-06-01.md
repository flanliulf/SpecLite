### Challenges（挑战）

- Redaction 风险在 source label 层比 URL 层更隐蔽。Story 5.1 证明 package selector 内嵌 query/token 也必须走 sanitizer，不能只检查 credential URL 或 absolute path。
- Registry source 容易把 package identity 复制到顶层 display 字段。Story 5.2 将 package identity 收敛到 evidence，避免 public projection 形成第二套 automation contract。
- Local source 的 public descriptor 与 private install root 必须分离。Story 5.3 如果只记录 descriptor 而不把 private root 贯穿 install，会造成 manifest/sourceDescriptor 与实际安装内容不一致。
- Git source pinning 不能只做字符串 shape 检查。Story 5.4 要求 resolver 证明 ref / SHA 是 commit-ish，validate 也必须拒绝落盘 malformed Git descriptor。
- SourceDescriptor trust reporting 的 touched surface 很宽。Story 5.5 经多轮 CR 才把 runtime gate、renderer、schema、validation、tests 和 touched-surface typecheck 诊断全部收口。
- Epic 5 定义文件仍保留旧摘要 AC 文案的非阻塞 SR defer。当前 Story 文件已经是更精确的开发输入，但跨文档摘要一致性需要单独授权处理。

### Key Lessons（关键经验）

1. Raw source locator 只能留在 private in-memory state；进入 public JSON、manifest/index、fixture snapshot、issue details 或 human output 前必须 display-safe / redacted。
2. `trusted` 必须来自 verified trust anchor，例如 expected hash、lock match 或 bundled packaging trust anchor；source 类型本身不能直接赋予 trust。
3. `unverified` 表示 evidence 可复现但缺少背书，不等于校验失败；`blocked` 表示不能进入写入步骤。
4. `speclite validate` 对 source integrity 必须 local-only：只读已安装 descriptor/evidence shape 和一致性，不访问 registry、Git remote、tarball/offline origin、cache 或 provenance service。
5. Confirmed external access state 是 audit surface 的一部分。runtime gate 生效还不够，human-readable output 也必须正确表达 pending/confirmed。
6. Touched-surface typecheck 诊断应与全仓既有类型债务分开处理；当前 Story 引入或暴露的诊断必须清零，但不能把 retrospective 扩大成全仓 typecheck 修复。
