[Overview]
    Generate SpecLite-owned single-file HTML PPT decks. This Skill vendors the templates, layouts, themes, and Swiss validator previously supplied by the external `guizang-ppt-skill`, so docs deck production is reproducible from SpecLite canonical source and release packages.

[Core Capabilities]
    - **Local template generation**: Use this Skill's `assets/template.html` or `assets/template-swiss.html` to create a horizontal deck.
    - **Two visual systems**: Provide electronic magazine style and Swiss Style templates, themes, and layout references.
    - **Layout constraints**: Require layouts to come from `references/layouts.md` or `references/layouts-swiss.md`; do not invent ad hoc page structures.
    - **Output directory control**: Write `index.html` to the confirmed target directory and put images in a sibling `images/` directory.
    - **Verification closeout**: Run `scripts/validate-swiss-deck.mjs`, placeholder scans, `git diff --check`, and browser sampling when available.
    - **Transparent attribution**: Keep template provenance and the MIT license in `references/third-party-notices.md`; never encode external installation paths in canonical workflow.

[Workflow]
    This Skill combines sequential workflow orchestration with iterative verification. Detailed steps, style selection, file paths, and stop conditions are in `references/html-ppt-generation-workflow.md`.

    1. Confirm topic, audience, output directory, style, slide count, materials, and constraints.
    2. Read this Skill's template, theme, layout reference, and quality checklist.
    3. Copy the selected template to `<output_dir>/index.html` and create `<output_dir>/images/`.
    4. Replace `<title>`, remove template placeholders, and insert the planned slide sections.
    5. For Swiss Style, run `scripts/validate-swiss-deck.mjs`; for every deck, run placeholder and whitespace checks.
    6. If browser automation is available, inspect first/last slide screenshots and per-slide overflow; otherwise state that visual verification was not performed.

[Notes]

    - Do not reference personal global skill paths or external `guizang-ppt-skill` installation paths; all templates, references, and validators must be read from this Skill package.
    - Technical, engineering, governance, data, and matrix-heavy topics default to Swiss Style; narrative, brand, and industry-observation topics may use the electronic magazine style.
