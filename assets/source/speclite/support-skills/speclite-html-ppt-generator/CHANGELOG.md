# Changelog

## [1.0.0] - 2026-07-06

### Added
- 新增 `speclite-html-ppt-generator` support skill，用于生成 SpecLite-owned 单文件 HTML PPT。
- 收纳电子杂志风与 Swiss Style 的模板、layout、theme、checklist、image prompt reference 和 Swiss validator。
- 增加双语入口 `SKILL.md` 与 `SKILL.en.md`，明确禁止依赖外部个人 skill 路径。
- 增加 `references/html-ppt-generation-workflow.md`，承载详细生成流程、验证命令和停止条件。
- 增加 `references/third-party-notices.md`，记录模板资产来源与 MIT license。

### Known Limitations
- Swiss Style 有内置 validator；电子杂志风仍主要依赖 checklist、占位符扫描、浏览器预览和人工视觉检查。
