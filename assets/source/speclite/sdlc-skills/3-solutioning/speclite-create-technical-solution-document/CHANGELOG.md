# Changelog

本文件记录 `speclite-create-technical-solution-document` 的版本变更。

## [1.0.0] - 2026-08-21

### Added

- 新增从 SpecLite 规划产物和项目事实生成面向人类的技术方案说明文档能力。
- 新增范围裁剪、证据状态、跨系统契约、Mermaid 图表与需求追溯规则。
- 新增 Markdown 技术方案模板、详细 workflow 和质量检查 references。
- 新增确定性结构验证脚本及 `Draft` / `Final` 两种检查模式。

### Known Limitations

- v1.0.0 不负责将 Markdown 导出为 PDF 或 Word。
- Mermaid 完整语法和渲染兼容性仍需目标项目的 Mermaid renderer 验证。
