# Tutorials（教程）

Tutorial 文档用于带新用户从零完成一条完整路径，并获得可验证结果。

## Documents（文档）

| 文档 | 说明 |
|---|---|
| [`speclite-orientation.md`](speclite-orientation.md) | 用 10–15 分钟建立 SpecLite 全景、核心术语、三层运行边界和首次使用路线。 |
| [`speclite-developer-training.md`](speclite-developer-training.md) | 将 13 篇材料组织成一场 3 小时开发者入门培训，包含议程、实验和验收清单。 |
| [`quick-start.md`](quick-start.md) | 按 preview、write authorization、状态检查和输出边界完成首次学习路径。 |
| [`first-brownfield-project.md`](first-brownfield-project.md) | 在小型既有项目中完成第一次 evidence-first baseline，并验证业务代码未被修改。 |

## Suggested Paths（建议路径）

- 个人初学：`speclite-orientation.md` → `quick-start.md` → `first-brownfield-project.md`。
- 组织培训：从 `speclite-developer-training.md` 开始，按其中的 13 篇材料顺序授课和验收。
