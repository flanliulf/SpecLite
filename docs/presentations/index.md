# Presentations（演示材料）

本目录保存用于分享、演讲或发布展示的 Supplementary Public Material（公开补充材料）。Presentation 可以重新组织视觉叙事，但不能成为规范来源，也不能承载主要公开文档中不存在的关键契约结论。

## Catalog（目录）

| Presentation | Audience | Source Documents |
|---|---|---|
| [`canonical-source-governance/`](canonical-source-governance/README.md) | SpecLite 维护者、架构师与方法论贡献者 | canonical source layout、governance、runtime boundaries |

## Maintenance Rules（维护规则）

新增 Presentation 时必须：

1. 在主题目录中提供 `README.md`，记录目标受众、适用范围、生成日期或适用版本。
2. 从主题 README 链接 deck 入口和支撑结论的主要公开文档。
3. 在本 catalog 登记入口。
4. 运行 `npm run docs:check`，验证 Markdown、HTML 入口和事实来源链接。
