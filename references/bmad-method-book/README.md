# BMAD-METHOD: AI 驱动敏捷开发的架构剖析

这是一本基于 [BMAD-METHOD](https://github.com/bmad-code-org/BMAD-METHOD) 源码的架构分析著作，从第一性原理剖析其设计选择、架构决策和哲学立场。

## 关于本书

**定位**：架构分析与最佳实践

**目标读者**：
- 系统架构师
- 应用开发者
- 团队技术负责人
- AI 原生开发工具设计者

**核心价值**：
- 深入分析 BMAD-METHOD 的设计哲学
- 提炼可复用的架构模式
- 诚实呈现设计权衡和代价
- 提供具体数字和源码证据

## 五大设计原则

1. **简单透明优于复杂高效**
2. **人类增强优于自动化**
3. **标准化与定制化并存**
4. **质量优于速度**
5. **开发者友好优于用户友好**

**统一原则**：尊重开发者、尊重约束、尊重真相、尊重协作
