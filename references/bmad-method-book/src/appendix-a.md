## 数据流图

### 安装流程数据流

```
用户命令
   │
   ├─> npx bmad-method install
   │
   v
┌─────────────────────────────────────────┐
│ 1. 配置收集                              │
│    - 交互式提示 (模块、IDE、配置)         │
│    - 或非交互式参数 (--modules, --tools) │
└─────────────────────────────────────────┘
   │
   v
┌─────────────────────────────────────────┐
│ 2. 现有安装检测                          │
│    - 读取 _bmad/_config/manifest.yaml   │
│    - 检测已安装模块和版本                │
└─────────────────────────────────────────┘
   │
   v
┌─────────────────────────────────────────┐
│ 3. 用户文件备份                          │
│    - 读取 files-manifest.csv            │
│    - 哈希对比识别修改文件                │
│    - 备份到临时目录                      │
└─────────────────────────────────────────┘
   │
   v
┌─────────────────────────────────────────┐
│ 4. 模块源解析                            │
│    - 内置模块 (src/core-skills/)        │
│    - 外部官方模块 (GitHub)               │
│    - 社区模块 (registry)                 │
│    - 自定义模块 (Git URL)                │
└─────────────────────────────────────────┘
   │
   v
┌─────────────────────────────────────────┐
│ 5. Git 克隆 (外部模块)                   │
│    - 克隆到 ~/.bmad/cache/               │
│    - 切换到指定版本/通道                 │
│    - 计算 SHA                            │
└─────────────────────────────────────────┘
   │
   v
┌─────────────────────────────────────────┐
│ 6. 文件复制                              │
│    - 复制模块文件到 _bmad/               │
│    - 计算 SHA256 哈希                    │
│    - 记录到 files-manifest.csv          │
└─────────────────────────────────────────┘
   │
   v
┌─────────────────────────────────────────┐
│ 7. 配置生成                              │
│    - 生成 config.toml (四层合并)         │
│    - 生成 module.yaml (模块配置)         │
│    - 应用 --set 覆盖                     │
└─────────────────────────────────────────┘
   │
   v
┌─────────────────────────────────────────┐
│ 8. 清单生成                              │
│    - 扫描 SKILL.md (技能发现)            │
│    - 生成 skill-manifest.csv            │
│    - 生成 manifest.yaml                 │
│    - 生成 bmad-help.csv                 │
└─────────────────────────────────────────┘
   │
   v
┌─────────────────────────────────────────┐
│ 9. IDE 集成                              │
│    - 复制 Skills 到 .claude/skills/      │
│    - 复制 Skills 到 .agents/skills/      │
│    - 生成 .agent.md (GitHub Copilot)    │
└─────────────────────────────────────────┘
   │
   v
┌─────────────────────────────────────────┐
│ 10. 用户文件恢复                         │
│     - 恢复备份的自定义文件               │
│     - 合并用户修改                       │
└─────────────────────────────────────────┘
   │
   v
安装完成
```

   │

│    - 读取 persistent_facts (项目知识)    │

   │

   │

   │

## 性能关键路径

### 安装流程性能分析

| 步骤 | 平均耗时 | 瓶颈类型 | 优化建议 |
|------|---------|---------|---------|
| 配置收集 | <1s | 用户交互 | 非交互模式 |
| 现有安装检测 | <0.1s | 文件 I/O | 无需优化 |
| 用户文件备份 | 1-2s | 文件 I/O + 哈希 | 并行哈希 |
| 模块源解析 | <0.5s | 网络 I/O | 缓存注册表 |
| **Git 克隆** | **5-30s** | **网络 I/O** | **浅克隆** |
| **文件复制** | **1-5s** | **磁盘 I/O** | **增量复制** |
| 配置生成 | <0.5s | CPU | 无需优化 |
| **清单生成** | **2-10s** | **文件 I/O** | **并行扫描** |
| IDE 集成 | 1-3s | 文件 I/O | 无需优化 |
| 用户文件恢复 | <1s | 文件 I/O | 无需优化 |
| **总计** | **10-50s** | - | - |

**三大瓶颈**：
1. Git 克隆（5-30s）
2. 清单生成（2-10s）
3. 文件复制（1-5s）
